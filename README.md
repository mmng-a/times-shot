# Times Shot

Slackを開かずに、自分のtimesへテキストと画像を投稿するmacOS用メニューバーアプリです。macOS 27.0以降に対応します。画面はSwiftUI、ウインドウ・入力・ショートカットは必要な箇所だけAppKitとCarbonを使用し、外部ライブラリには依存しません。

## ビルド

Xcode 27以降を選択した状態で実行します。

```sh
bash scripts/test.sh
bash scripts/build-app.sh
```

`dist/Times Shot.app`をApplicationsフォルダへコピーして開いてください。初期状態ではローカル用のアドホック署名を付けます。署名証明書がある場合は、`SIGNING_IDENTITY`環境変数で指定できます。

## Slackの設定

1. Slackアプリの「OAuth & Permissions」で、**User Token Scopes**に`chat:write`と`files:write`を追加します。
2. ワークスペースへインストールし、本人の**User OAuth Token**（`xoxp-`から始まるもの）を取得します。Bot Tokenは使用しません。
3. 投稿先のtimesチャンネルへ本人が参加していることを確認し、チャンネル詳細からチャンネルIDをコピーします。
4. Times Shotの設定にトークン・チャンネルID・表示用のチャンネル名を入力し、「接続を確認して保存」を選びます。接続確認では投稿しません。
5. エラー通知を受け取るため、macOSの通知を許可してください。ログイン時起動は初回起動時に有効化を試み、設定から変更できます。OSの承認が必要な場合はシステム設定で許可してください。

認証情報はKeychainに保存します。トークンを設定ファイルやログへ出力しません。接続方法の根拠は[chat.postMessage](https://docs.slack.dev/reference/methods/chat.postMessage/)と[files.completeUploadExternal](https://docs.slack.dev/reference/methods/files.completeUploadExternal/)を参照してください。

## 操作

| 操作 | 動作 |
| --- | --- |
| Shift + Space | 入力画面の表示・非表示。下書きを保持 |
| ⌘W、ウインドウの閉じるボタン | 下書きを保持して閉じる |
| Esc | 本文・画像を破棄して閉じる。日本語変換中は変換の取り消しを優先 |
| Enter | 改行 |
| ⌘Enter、送信ボタン | キューへ追加して入力画面を閉じる |
| ⌘V | 画像またはプレーンテキストを貼り付ける |
| 画像のドロップ、添付ボタン | 画像を添付する |

送信待ちがあっても次の投稿を書けます。送信は受付順に1件ずつ行い、Slackの制限に合わせて間隔を空けます。投稿時の接続先を保持するため、その後の設定変更が送信待ちの投稿先を変えることはありません。送信中はメニューバーに件数を表示し、成功通知は出しません。

失敗時は本文冒頭・画像名・原因を通知し、その投稿を破棄して次へ進みます。自動再送・履歴・復元はありません。投稿結果が不明な場合も再送しません。通知を許可していない場合はメニューバーのエラー表示で確認できます。エラー表示は直近1件のみで、アプリ終了時に消えます。

送信中・送信待ちがある状態で終了する場合は確認します。「破棄して終了」を選ぶと残りを破棄しますが、送信中の投稿はSlack側で完了する可能性があります。入力中の下書きは別に保持します。異常終了時の送信キューは復元しません。

## 画像・Markdown

PNG・JPEG・GIF・WebPは元データを保持し、HEIC・TIFF・BMPなど、ImageIOで読み込める静止画像はPNGへ変換します。GIFなどを静止画へ変換しません。変換が必要な複数フレーム画像は、意図せず内容を失わないよう添付時にエラーを表示します。画像のサムネイルは縮小して生成し、投稿用画像は縮小しません。

Markdownは`**太字**`、`*斜体*`、`~~取り消し線~~`、インラインコード、コードブロック、引用、箇条書き、番号付きリスト、`[リンク](URL)`に対応します。投稿時にSlackの記法へ変換します。見出し・表・HTML・画像埋め込み・メンション候補・プレビューには対応しません。装飾の変換仕様は[Slackのmrkdwn仕様](https://docs.slack.dev/messaging/formatting-message-text/)に従います。

下書きと添付画像は`~/Library/Application Support/TimesShot/`に保存し、送信が終了した画像や破棄した画像は削除します。

## 検証

自動テストでは、Markdown変換、キューの順序と失敗後の継続、終了時のキャンセル、Slackへのリクエスト順序、アップロード失敗時の本文単独投稿の防止、結果不明時の再送防止、画像変換・下書き保存を確認します。通信テストはモックを使用し、実際のSlackへ投稿しません。

実際のSlack接続後に、本人名義の投稿、画像付き投稿、グローバルショートカット、IME、フルスクリーン、元のアプリへの復帰、通知、自動起動を実機で確認してください。
