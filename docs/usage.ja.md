## Slackへの接続と投稿先

1. 設定の「一般」で「Slackに接続」を押す。
2. ブラウザでワークスペースとアカウントを確認し、要求する権限を許可する。ワークスペースによっては管理者の承認が必要。
3. 設定の「チャンネル」で名前を検索し、一覧の行か「＋」から投稿先を登録する。
4. 入力画面上部のメニューで投稿先を選ぶ。

一覧の対象は、参加済みの公開・プライベートチャンネル。アーカイブ済みチャンネルとDMは含まない。「一覧を再取得」で候補を更新できる。登録を解除する場合は「登録した投稿先」で行を選び、「−」を押す。

選んだ投稿先は投稿後や再起動後も保持される。同じワークスペース・アカウントへの再接続でも登録は残る。下書きがある間は、選択中の投稿先の削除や、別のワークスペース・アカウントへの接続はできない。

認証情報はKeychainに保存され、一覧取得・送信時に有効期限を確認して更新される。再接続が必要な場合は「一般」の「Slackに再接続」を使う。「接続解除」で削除するのはこのMacの認証情報で、投稿先や下書きは残る。Slack App自体の削除はSlack側のアプリ管理で行う。

送信中・送信待ち、画像の読み込み中は、再接続・接続解除を行えない。ログイン時起動と通知は設定から変更できる。ログイン時起動は初回に有効化を試みるため、OSの承認を求められた場合はシステム設定で許可する。

## 操作

| 操作 | 動作 |
| --- | --- |
| Shift + Space | 入力画面の表示・非表示。下書きを保持 |
| ⌘W、閉じるボタン | 下書きを保持して閉じる |
| Esc | 本文・画像を破棄して閉じる。日本語変換中は変換の取り消しを優先 |
| Enter | 改行 |
| ⌘Enter、送信ボタン | キューへ追加して入力画面を閉じる |
| ⌘V | 画像または書式付きテキストを貼り付ける |
| ⌘⇧A、ツールバーのクリップ | 画像を添付する |
| ⌘,、メニューバーの「設定…」 | 設定を開く |
| ⌘B、⌘I | 太字・斜体を切り替える |
| ⌘⇧X、⌘⇧C | 取り消し線・コードを切り替える |
| ⌘Z、⌘⇧Z | 編集・書式変更を取り消す・やり直す |
| 画像のドロップ | 画像を添付する |
| 投稿先メニュー | 登録したチャンネルを切り替える。本文と添付は保持 |

投稿・添付・チャンネル切り替えは「投稿」メニューからも操作できる。

## 送信と下書き

送信待ちがあっても次の投稿を書ける。送信は受付順に1件ずつ、Slackの制限に合わせて間隔を空けて行う。キューへ追加した投稿は、その後に投稿先を切り替えても元のチャンネルへ送信される。メニューバーには待機件数を表示し、成功通知は出さない。

失敗時の通知には本文冒頭・画像名・原因を表示する。失敗した投稿は破棄し、次へ進む。自動再送・履歴・復元はなく、結果が不明な場合も再送しない。通知を許可していない場合はメニューバーのエラー表示で確認できる。エラー表示は直近1件のみで、終了時に消える。

送信中・送信待ちがある状態で終了する場合は確認が入る。「破棄して終了」で残りを破棄できるが、送信中の投稿はSlack側で完了する可能性がある。入力中の下書きは別に保持され、異常終了時のキューは復元されない。

下書きは文字と書式を保存し、再起動後も復元される。下書きと添付画像の保存先は`~/Library/Application Support/TimesShot/`。送信が終了した画像や破棄した画像は削除される。

## 画像と書式

PNG・JPEG・GIF・WebPは元データを保持する。HEIC・TIFF・BMPなど、ImageIOで読み込める静止画像はPNGへ変換する。GIFなどを静止画へ変換することはなく、変換が必要な複数フレーム画像は添付時にエラーとなる。サムネイルは縮小するが、投稿用画像は縮小しない。

本文はmacOS標準のリッチテキスト入力。文字を選択し、ショートカットか右クリックの「書式」から太字・斜体・取り消し線・コードを切り替える。選択せずに切り替えた場合は、その後の入力へ適用される。書式付きテキストの貼り付けではリンクも保持される。改行を含むコードはSlackのコードブロックとして投稿される。

入力中の記号からも書式を設定できる。閉じる記号を入力すると、記号が消えて囲んだ文字に書式が付く。

| 入力 | 変換結果 |
| --- | --- |
| `*太字*`、`**太字**` | 太字 |
| `_斜体_` | 斜体 |
| `~取り消し~`、`~~取り消し~~` | 取り消し線 |
| `` `コード` `` | コード |
| 行頭の`- `、`* ` | 箇条書き |

箇条書きではEnterで次の項目を作り、空の項目でEnterを押すと通常の段落へ戻る。項目の先頭でBackspaceを押しても解除できる。自動変換は⌘Zで取り消せる。日本語変換中とコード内では変換せず、直前にバックスラッシュを入力した記号も変換しない。

本文をすべて削除すると書式は標準に戻る。空の状態で書式を選び直せば、その後の入力に適用できる。引用・番号付きリストは行頭に`> `・`1. `などを入力する。

投稿時には[Slackのmrkdwn仕様](https://docs.slack.dev/messaging/formatting-message-text/)へ変換する。フォントの種類・サイズ・色・下線は送信せず、見出し・表・HTML・本文内の画像・メンション候補には未対応。

## Slackの権限

要求するUser Token Scopesは次の4つ。会話履歴を取得する権限は要求しない。

| 権限 | 用途 |
| --- | --- |
| `chat:write` | 本人名義のテキスト投稿 |
| `files:write` | 画像のアップロード・共有 |
| `channels:read` | 公開チャンネルの基本情報取得 |
| `groups:read` | 参加済みプライベートチャンネルの基本情報取得 |

接続と一覧取得は[PKCE](https://docs.slack.dev/authentication/using-pkce/)・[users.conversations](https://docs.slack.dev/reference/methods/users.conversations/)、投稿は[chat.postMessage](https://docs.slack.dev/reference/methods/chat.postMessage/)・[files.completeUploadExternal](https://docs.slack.dev/reference/methods/files.completeUploadExternal/)を使用する。
