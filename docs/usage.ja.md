## Slackへの接続と投稿先

1. 設定の「一般」で「Slackに接続」を選択してください。
2. ブラウザでワークスペースとアカウントを確認し、要求する権限を許可してください。ワークスペースによっては、管理者の承認が必要です。
3. 設定の「チャンネル」で名前を検索し、一覧の行か「＋」から投稿先を登録してください。
4. 入力画面上部のメニューから、投稿先を選択してください。

一覧に表示されるのは、参加済みの公開・プライベートチャンネルです。アーカイブ済みチャンネルとDMは含まれません。「一覧を再取得」で候補を更新できます。登録を解除する場合は、「登録した投稿先」で行を選び、「−」を押してください。

選んだ投稿先は、投稿後やアプリの再起動後も保持されます。同じワークスペース・アカウントへの再接続でも登録が残るため、選び直す必要はありません。下書きがある間は、選択中の投稿先の削除や、別のワークスペース・アカウントへの接続が制限されます。変更する場合は、先に下書きを送信または破棄してください。

認証情報はKeychainに保存され、一覧取得・送信時に有効期限を確認して更新されます。再接続が必要な場合は、設定の「一般」にある「Slackに再接続」を使ってください。「接続解除」で削除されるのはこのMacの認証情報で、投稿先や下書きは残ります。Slack App自体を削除する場合は、Slack側のアプリ管理で操作してください。

送信中・送信待ち、画像の読み込み中は、再接続・接続解除を行えません。ログイン時起動と通知は設定から変更できます。ログイン時起動は初回に有効化を試みるため、OSの承認を求められた場合はシステム設定で許可してください。

## 操作

| 操作 | 動作 |
| --- | --- |
| Shift + Space | 入力画面の表示・非表示。下書きを保持 |
| ⌘W、閉じるボタン | 下書きを保持して閉じる |
| Esc | 本文・画像を破棄して閉じる。日本語変換中は変換の取り消しを優先 |
| Enter | 改行 |
| ⌘Enter、送信ボタン | キューへ追加して入力画面を閉じる |
| ⌘V | 画像または書式付きテキストを貼り付ける |
| ⌘⇧A、ツールバーのクリップ | 画像を添付する |
| ⌘,、メニューバーの「設定…」 | 設定を開く |
| ⌘B、⌘I | 太字・斜体を切り替える |
| ⌘⇧X、⌘⇧C | 取り消し線・コードを切り替える |
| ⌘Z、⌘⇧Z | 編集・書式変更を取り消す・やり直す |
| 画像のドロップ | 画像を添付する |
| 投稿先メニュー | 登録したチャンネルを切り替える。本文と添付は保持 |

投稿・添付・チャンネル切り替えは、「投稿」メニューからも操作できます。

## 送信と下書き

送信待ちがある間も、次の投稿を入力できます。送信は受付順に1件ずつ、Slackの制限に合わせて間隔を空けて行われます。キューへ追加した投稿の送信先は、その後にチャンネルを切り替えても変わりません。メニューバーには待機件数が表示され、成功通知は出ない仕様です。

送信エラーの通知には、本文冒頭・画像名・原因が表示されます。失敗した投稿は破棄し、次の投稿へ進みます。自動再送・履歴・復元はなく、結果が不明な場合も再送しません。通知を許可していない場合は、メニューバーのエラー表示を確認してください。表示されるのは直近1件のエラーのみで、アプリ終了時に消えます。

送信中・送信待ちがある状態でアプリを終了するときは、確認が入ります。「破棄して終了」を選ぶと残りの投稿は破棄されますが、送信中の投稿はSlack側で完了する可能性があります。入力中の下書きは別に保持される一方、異常終了時の送信キューは復元できません。

下書きは文字と書式を保存し、再起動後も復元されます。下書きと添付画像の保存先は`~/Library/Application Support/TimesShot/`です。送信が終了した画像や破棄した画像は削除されます。

## 画像と書式

PNG・JPEG・GIF・WebPは、元のデータを保持して送信します。HEIC・TIFF・BMPなど、ImageIOで読み込める静止画像はPNGに変換されます。GIFなどを静止画に変換することはありません。変換が必要な複数フレーム画像は、添付時にエラーとなります。縮小されるのはサムネイルだけで、投稿用画像は元のサイズです。

本文には、macOS標準のリッチテキスト入力を使用しています。文字を選択し、ショートカットか右クリックの「書式」から、太字・斜体・取り消し線・コードを切り替えてください。文字を選択していない場合は、その後の入力に適用されます。書式付きテキストの貼り付けではリンクも保持され、改行を含むコードはSlackのコードブロックとして投稿されます。

入力中の記号から書式を設定することもできます。閉じる記号を入力すると、記号が消えて、囲んだ文字に書式が付きます。

| 入力 | 変換結果 |
| --- | --- |
| `*太字*`、`**太字**` | 太字 |
| `_斜体_` | 斜体 |
| `~取り消し~`、`~~取り消し~~` | 取り消し線 |
| `` `コード` `` | コード |
| 行頭の`- `、`* ` | 箇条書き |

箇条書きではEnterで次の項目を作成し、空の項目でEnterを押すと通常の段落に戻ります。項目の先頭でBackspaceを押しても解除できます。自動変換を取り消す場合は、⌘Zを押してください。日本語変換中とコード内では変換せず、直前にバックスラッシュを入力した記号も変換しません。

本文をすべて削除すると、書式は標準に戻ります。空の状態で書式を選び直せば、その後の入力に適用できます。引用・番号付きリストを使う場合は、行頭に`> `・`1. `などを入力してください。

投稿時には、[Slackのmrkdwn仕様](https://docs.slack.dev/messaging/formatting-message-text/)に変換されます。フォントの種類・サイズ・色・下線は送信されません。見出し・表・HTML・本文内の画像・メンション候補は未対応です。

## Slackの権限

要求するUser Token Scopesは次の4つです。会話履歴を取得する権限は要求しません。

| 権限 | 用途 |
| --- | --- |
| `chat:write` | 本人名義のテキスト投稿 |
| `files:write` | 画像のアップロード・共有 |
| `channels:read` | 公開チャンネルの基本情報取得 |
| `groups:read` | 参加済みプライベートチャンネルの基本情報取得 |

接続と一覧取得には[PKCE](https://docs.slack.dev/authentication/using-pkce/)・[users.conversations](https://docs.slack.dev/reference/methods/users.conversations/)、投稿には[chat.postMessage](https://docs.slack.dev/reference/methods/chat.postMessage/)・[files.completeUploadExternal](https://docs.slack.dev/reference/methods/files.completeUploadExternal/)を使用しています。
